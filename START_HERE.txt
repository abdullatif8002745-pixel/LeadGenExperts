👋 Welcome! This tool scrapes product information from online stores.

📖 COMPLETE GUIDE: Open "BEGINNER_GUIDE.md" for detailed instructions


⚡ QUICK START (Super Easy!)
════════════════════════════════════════════════════════════════

WINDOWS USERS:
--------------
1. Install Python from: https://www.python.org/downloads/
   (Check "Add Python to PATH" during installation!)

2. Double-click "QUICKSTART.bat"

3. Done! Your data will be in the "test_output" folder.


MAC/LINUX USERS:
----------------
1. Open Terminal

2. Navigate to this folder:
   cd ~/Desktop/LeadGenExperts

3. Run the quick start script:
   bash quickstart.sh

4. Done! Your data will be in the "test_output" folder.


📊 VIEWING YOUR DATA
════════════════════════════════════════════════════════════════

After running the scraper:
1. Go to the "output" or "test_output" folder
2. Open the .xlsx file with Excel or Google Sheets
3. All product data is there in a nice spreadsheet!


🎯 SCRAPING YOUR OWN PRODUCTS
════════════════════════════════════════════════════════════════

1. Find a product on Amazon, eBay, etc.
2. Copy the URL from your browser
3. Run this command:

   Windows:
   venv\Scripts\activate
   python main.py --url "PASTE_URL_HERE" --format all

   Mac/Linux:
   source venv/bin/activate
   python main.py --url "PASTE_URL_HERE" --format all

4. Check the "output" folder for your data!


📝 SCRAPING MULTIPLE PRODUCTS
════════════════════════════════════════════════════════════════

1. Create a text file (e.g., "products.txt")
2. Add one product URL per line
3. Run:
   python main.py --file products.txt --format all
